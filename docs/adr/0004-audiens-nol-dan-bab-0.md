# Audiens belum pernah koding, dengan bab 0 alat

Alternatifnya memakai audiens lanjutan atau pengguna desain. Dipilih audiens nol karena seri ini berdiri sendiri sebagai pintu masuk, sehingga setiap asumsi sebelumnya harus diajarkan. Konsekuensinya: ada bab 0 "Siapkan Alat" dan aturan tanpa jargon sebelum didefinisikan.
