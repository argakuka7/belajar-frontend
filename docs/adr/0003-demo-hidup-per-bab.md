# Satu blok demo hidup per bab

Buku frontend punya keunggulan yang tidak dimiliki buku backend: halamannya bisa mendemokan dirinya sendiri. Setiap bab muat satu blok demo interaktif yang memanggil kode bab itu. Biayanya kecil (HTML statis tanpa build tool), manfaatnya pembaca nol pengalaman bisa mencoba tanpa instalasi.
