# Kontrak Kuka: Bab 0 Siapkan Alat

Kembali ke [overview](overview.md).

Kuka adalah persona ilustrasi seri ini. Kontrak ini memesan ilustrasi untuk diproduksi pada fase ilustrasi. Path dan alt text di bawah sudah dipakai di halaman publik, jadi ilustrator harus memenuhi nama file dan deskripsi ini.

## Ilustrasi 1: Kuka di depan editor

- **File**: `public/00-siapkan-alat/img/kuka-editor.png`
- **Alt text**: Kuka duduk di depan layar yang menampilkan jendela editor VS Code dengan baris kode berwarna.
- **Penempatan**: setelah paragraf pembuka, sebelum bagian "Pasang editor".
- **Deskripsi**: Kuka menghadap layar besar. Di layar tampak jendela editor dengan sidebar kiri dan baris kode berwarna. Kuka memegang keyboard. Gaya kartun datar, warna hangat senada aksen oranye situs.

## Ilustrasi 2: Kuka membuka DevTools

- **File**: `public/00-siapkan-alat/img/kuka-devtools.png`
- **Alt text**: Kuka menunjuk panel Console di DevTools yang menampilkan teks "Halo, dunia!".
- **Penempatan**: di dalam blok Demo Hidup, sebelum tombol.
- **Deskripsi**: Kuka berdiri di samping browser. Di layar browser terbuka panel DevTools di bagian bawah, dengan tab Console aktif dan satu baris teks. Kuka menunjuk baris itu. Gaya sama dengan ilustrasi 1.
