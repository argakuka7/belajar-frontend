# Konsep Bab 0: Siapkan Alat

Kembali ke [overview](overview.md).

## Tujuan bab

Pembaca belum pernah koding. Bab ini menyiapkan tiga alat yang dipakai sepanjang seri: editor teks, browser, dan DevTools. Tidak ada konsep bahasa pemrograman di sini. Yang ada hanya cara memasang dan mengenal alat, supaya bab berikutnya bisa langsung menulis kode.

## Dua pertanyaan wajib

1. Mengapa alat ini ada: editor untuk menulis kode, browser untuk menjalankan dan melihat hasil, DevTools untuk memeriksa halaman.
2. Bagaimana cara kerjanya di baliknya: editor menyimpan teks polos, browser membaca file itu, DevTools membuka jendela inspeksi di dalam browser.

## Garis besar

- Editor VS Code: apa itu, cara memasang, cara membuka folder, kenapa teks polos.
- Browser: peran browser sebagai tempat hasil tampil, cara membuka file lokal.
- DevTools: cara membuka, panel Console, kenapa console berguna.
- Demo Hidup: tombol yang memanggil `console.log`, dengan instruksi membuka console.

## Pasangan contoh

- Vanilla: `console.log` langsung di file JavaScript.
- React: `console.log` di dalam komponen React.
