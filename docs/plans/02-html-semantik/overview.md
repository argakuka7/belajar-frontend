## Ringkasan

Bab 2 menjelaskan kenapa HTML adalah struktur terpenting dan kenapa memilih elemen yang tepat itu soal makna, bukan sekadar tampilan. Ini bab pertama yang membahas satu bahasa secara mendalam, jadi setiap istilah didefinisikan saat pertama muncul.

## Produk

- Naskah sumber di folder ini: konsep, kontrak Kuka, overview.
- Halaman publik: `public/02-html-semantik/index.html`.
- Ilustrasi Kuka dipesan lewat `kontrak-kuka.md`, diproduksi di fase ilustrasi.

## Verifikasi

Halaman terbuka tanpa error console. Demo Hidup mengganti div soup dengan markup semantik sekali klik. Prosa lolos STYLE_GUIDE.
