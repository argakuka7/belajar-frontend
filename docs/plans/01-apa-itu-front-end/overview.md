# Overview Bab 1: Apa Itu Front End

Kembali ke [overview program](../000-launch/overview.md).

## Ringkasan

Bab 1 menjelaskan apa itu front end dan bagaimana browser menyusun halaman. Ini bab pertama yang memuat konsep teknis, jadi setiap istilah didefinisikan saat pertama muncul.

## Produk

- Naskah sumber di folder ini: konsep, kontrak Kuka, overview, tiga fase produksi.
- Halaman publik: `public/01-apa-itu-front-end/index.html`.
- Ilustrasi Kuka dipesan lewat `kontrak-kuka.md`, diproduksi di fase ilustrasi.

## Fase

- [phase-1-scaffold.md](phase-1-scaffold.md): kerangka halaman dan struktur folder.
- [phase-2-konten.md](phase-2-konten.md): naskah dan pasangan contoh.
- [phase-3-ilustrasi.md](phase-3-ilustrasi.md): produksi ilustrasi Kuka.
