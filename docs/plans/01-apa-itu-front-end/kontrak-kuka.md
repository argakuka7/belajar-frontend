# Kontrak Kuka: Bab 1 Apa Itu Front End

Kembali ke [overview](overview.md).

Kuka adalah persona ilustrasi seri ini. Kontrak ini memesan ilustrasi untuk diproduksi pada fase ilustrasi. Path dan alt text di bawah sudah dipakai di halaman publik, jadi ilustrator harus memenuhi nama file dan deskripsi ini.

## Ilustrasi 1: Kuka melihat alur browser

- **File**: `public/01-apa-itu-front-end/img/kuka-alur-browser.png`
- **Alt text**: Diagram alur dari HTML menuju DOM, render tree, lalu paint, dengan Kuka di sampingnya.
- **Penempatan**: setelah paragraf pembuka, sebelum bagian "Cara browser menyusun halaman".
- **Deskripsi**: Diagram empat kotak berurutan dengan panah: HTML, DOM, render tree, paint. Kuka berdiri di samping diagram sambil menunjuk kotak pertama. Gaya kartun datar, warna hangat senada aksen oranye situs.

## Ilustrasi 2: Kuka memegang tiga bahasa

- **File**: `public/01-apa-itu-front-end/img/kuka-tiga-bahasa.png`
- **Alt text**: Kuka memegang tiga kartu bertuliskan HTML, CSS, dan JavaScript.
- **Penempatan**: di bagian "Kenapa tiga bahasa terpisah".
- **Deskripsi**: Kuka memegang tiga kartu besar. Kartu pertama bertuliskan HTML, kedua CSS, ketiga JavaScript. Tiap kartu punya ikon kecil: kerangka untuk HTML, kuas untuk CSS, roda gigi untuk JavaScript. Gaya sama dengan ilustrasi 1.
